# AyurSutra Homepage

## Files
- `index.html` — complete homepage structure
- `style.css` — all styling, responsive layout and animations
- `script.js` — mobile menu, active navigation and therapy modal

## How to run
1. Put all three files in the same folder.
2. Open `index.html` in Chrome/Edge.
3. The page uses Google Fonts and online Unsplash images, so an internet connection is needed for the external fonts/images.

## To use your own images
Replace the `src="https://images.unsplash.com/..."` values in `index.html` with your own image paths, for example:
`src="images/nasya.jpg"`

## Important
The five therapy names/descriptions are based on the supplied design. For an actual healthcare product, have the clinical terminology and treatment descriptions reviewed by a qualified Ayurvedic/medical professional before deployment.
